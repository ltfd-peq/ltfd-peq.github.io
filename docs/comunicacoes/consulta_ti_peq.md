**Assunto:** Site do Laboratório de Termofluidodinâmica (LTFD): opções de domínio e hospedagem

Prezados,

O LTFD (PEQ/COPPE/UFRJ) vai publicar seu site institucional em 16/11/2026, inicialmente em
https://ltfd-peq.github.io/. O site é estático: não tem banco de dados nem código rodando no
servidor, e só contém informação pública (dados pessoais apenas com autorização dos membros).

Por isso, perguntamos:

1. O PEQ prefere (a) apenas criar o subdomínio apontando para o GitHub Pages, que continuaria
   hospedando o site, ou (b) hospedar o site num servidor do PEQ?

   federal sobre nuvem para um site estático, só com conteúdo público, hospedado fora da UFRJ?
3. Qual é o prazo usual de cada opção?
